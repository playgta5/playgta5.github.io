# playgta5

An archived browser-based GTA V port. The mirror is not included; use game data you are legally entitled to use.

Open [playgta5.github.io](https://playgta5.github.io/) over HTTPS in a current Chrome or Edge browser, then import your `.zip` or `.rar` mirror once. It is extracted locally and stays in that browser.

Use **Download local build** to export a ZIP64 package with the mirror. Extract it, then run `Launch-Local.cmd` on Windows, or `node server.js` with Node.js 22+.

The GitHub Pages version uses a service worker for cross-origin isolation and streams saved files from browser storage. No mirror data is uploaded.
